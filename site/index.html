Against what you pay for

Under Ofcom's Broadband Speed Code of Practice your provider must give a guaranteed minimum download speed. If measured speed sits below it and they cannot fix it within 30 days, you can normally exit the contract without penalty. These figures are measurements from a dedicated collector.

Run a test now

Asks this collector to test straight away instead of waiting for its schedule. It checks for requests every minute; the result shows here a few minutes later.

One-click setup

Requests go through this site's GitHub repository, so only people who can run its workflows can start a test. Without a token, Run now opens the workflow on GitHub for you to start there. With one, it starts it directly from this page.

  1. On GitHub, create a fine-grained personal access token.
  2. Limit it to only this repository, with the single permission Actions: Read and write. That lets it start workflows and nothing else: it cannot read or change code.
  3. Paste it below. It is kept in this browser only and is sent to nothing but api.github.com.
